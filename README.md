# Porto Extension for Scaffold-ETH 2

This extension adds [Porto](https://porto.sh/) to the list of available wallets user can connect to in Scaffold-ETH 2.

## Installation

```bash
npx create-eth@latest -e porto
```

> NOTE: porto currently only supports [certain chains](https://porto.sh/sdk/api/chains#supported-chains), so make sure to include only those chains in `scaffold.config.ts#targetNetworks`.
